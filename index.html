02 • ENSIKLOPEDIA AETHERIA

Materi: Hardware Komputer

Hardware adalah seluruh bagian fisik komputer yang dapat dilihat dan disentuh.

⌨️

Perangkat Input

Digunakan untuk memasukkan data atau perintah ke komputer.

Contoh: keyboard, mouse, scanner, mikrofon, webcam.

🧠

Perangkat Proses

Mengolah data dan menjalankan instruksi sesuai program.

Contoh: CPU/prosesor, GPU. Motherboard menghubungkan komponen.

🖥️

Perangkat Output

Menyajikan hasil pengolahan data agar dapat dilihat atau didengar pengguna.

Contoh: monitor, printer, speaker, proyektor.

💾

Perangkat Penyimpanan

Menyimpan data dan program, baik sementara maupun jangka panjang.

Contoh: RAM (sementara), HDD, SSD, flashdisk (jangka panjang).

🔌

Motherboard & PSU

Motherboard menjadi papan utama penghubung komponen. PSU memasok daya listrik untuk komputer.

🌬️

Pendingin & Casing

Heatsink dan kipas membantu membuang panas. Casing melindungi serta menata komponen komputer.

Media Pembelajaran Informatika

Application Overview

Hardware Chronicles adalah media pembelajaran berbasis web untuk membantu siswa kelas 7, 8, dan 9 mengenal perangkat keras komputer melalui narasi petualangan fantasi-sains, materi ringkas, kuis, dan aktivitas mencocokkan.

Petunjuk penggunaan

  • Gunakan menu navigasi untuk berpindah bagian tanpa memuat ulang halaman.
  • Pilih salah satu faksi sebagai avatar petualang.
  • Baca materi sebelum mengerjakan kuis dan latihan drag & drop.
  • Website dapat dibuka langsung melalui browser modern.

Catatan desain

Dunia, nama faksi, dan avatar dalam media ini merupakan kreasi orisinal dengan nuansa fantasi-sains: perpaduan ornamen kuno, simbol peradaban, kristal, dan teknologi futuristik. Desain mengambil inspirasi umum dari genre fantasi-sains, bukan menyalin karakter atau aset resmi Mobile Legends maupun Rising Force Online.
